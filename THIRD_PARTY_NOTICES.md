# Third-party components

Dependencies are installed from their package registries; their licenses and notices remain distributed with those packages. See `services/frontend/package-lock.json` and the Python requirements for the dependency lists.

Frontend components use React, React DOM, React Markdown, Lucide icons, Vite and Tailwind CSS. The backend uses FastAPI, Pydantic, OpenAI's Python SDK, LangChain Core, pypdf, NumPy and FAISS. The optional sample-document generator uses ReportLab.

The bundled room scene and fictional game splash are original generated artwork. The sample avatar and favicon are original SVG placeholders. No personal portrait, branded game artwork, external certification logo, commercial game sound effect or personalized title image is included. Entrance text uses system fonts. The layout and character animation do not depend on a commercial game engine or its assets.

Owners are responsible for choosing documents and replacement images they can publish with their own portfolios.
